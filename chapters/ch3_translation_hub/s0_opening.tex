The Platonic Representation Hypothesis proposes that models trained on similar data converge toward similar representations~\cite{huh2024platonic}.
If representations converge, the hidden states of two models encode the same prompt in related forms.
This work therefore investigates whether a decoder that reconstructs a prompt from one model's hidden states also reconstructs it from another's, once both are mapped into a shared space.
This chapter builds that shared space, the translation hub, from three open-weight language models and tests cross-model reconstruction.

\paragraph{Hypothesis: shared representations support cross-model inversion.} A token-wise hub trained on three open-weight models preserves enough input information for each frozen model to reconstruct the prompt from any other model's hub outputs.
Section~\ref{sec:hub:eval} states how the hypothesis is tested.
