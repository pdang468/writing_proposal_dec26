# Checklist, last pass before a section leaves your hands

Derived from principles.md; the reasons live there. Run this once, after revision, never while drafting.

- grep: "we", "our", "use", "using", "utilize", bare "this", "in order to", "boost", "leverage", intensifiers: zero hits.
- First three words of each sentence name something already introduced (except paragraph openers).
- Each sentence: subject meets verb within four words; one point; the point at the end.
- Each sentence over about 35 words passes those tests, or is a parallel list of at most four items.
- Each paragraph: first sentence is the claim; last sentence restates it and links forward; cover the body and the claim survives.
- Each number: comparator in the same sentence; seeds and prompt count; interval or test when a gap is claimed; label (result, control, threshold, selection).
- Each result paragraph: question or prediction, number against comparator, verdict, reading; the number first only when it is the surprise.
- Each claim: reach bounded once beside it; no hedge on a number; at most one "may" per paragraph.
- Each table: both sides, metric, n. Each figure caption: conclusion first, method second.
- Each term: glossary wording at first use, bare afterward; one term per thing.
- The section ends with what it asserts but does not show.
